# Nylan's Bag of Tricks

Small quality-of-life tweaks for WoW Forever. Each one can be switched on or off.

## Install

Copy the `NylansBagOfTricks` folder into `World of Warcraft\_forever_\Interface\AddOns\` and restart the game.

## Settings

Options > AddOns > Nylan's Bag of Tricks, or `/tricks`. Turning a trick on or off needs a `/reload`.

## Tricks

- **Mail Overhaul** (off by default): replaces the mailbox with a tabbed window. It has Open all, an address book of your alts and friends, and rules that pick which items go to whom. `/mo`
- **Gamepad Prompt:** when a controller connects, asks whether to switch to gamepad mode, and offers to switch back when it disconnects. `/gpprompt`
- **Auto Replace Enchant:** adds a checkbox to the enchanting window that skips the "replace existing enchant?" confirmation. `/autoreplace`
